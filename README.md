# Employee Onboarding & Internal Movement Portal

**Live demo:** https://onboarding-portal-lake.vercel.app

A one-day MVP demo prototype covering two journeys — **New Joiner** (register → HR approval → basic onboarding → team selection → manager approval → team onboarding) and **Internal Movement** (request a new team → new manager approval → new team onboarding). Pick demo users from the login dropdown; no passwords.

> Demo prototype: all data is stored in your browser's `localStorage`. Use **Reset demo data** in the header to start over.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # Vitest unit tests
```
